# 锅边笔记

独立菜谱页面： https://chanwang98.github.io/portfolio/recipes/

## 使用

- 打开页面即显示所有菜谱的食材、备菜、全部烹饪步骤、火候、时间和完成状态，不需要展开卡片。
- 搜索菜名、食材或心得，按分类筛选。
- 点击「记一道菜」新建；编辑支持步骤增删、上下移动，输入自动保存草稿，点击「保存菜谱」完成保存。
- 可勾选食材与备菜项，勾选仅作用于本次页面，不改变菜谱。
- 可选逐步计时模式，支持暂停、继续、重置；仅在页面运行时可靠，不保证锁屏或后台提醒。
- 「备份与设置」可导出 JSON / 合并导入。相同 ID 保留更新时间较新的版本。
- Safari 分享菜单可添加到主屏幕。页面需要网络加载，未实现离线缓存。

## 数据

菜谱保存在当前浏览器 localStorage 的 chan-kitchen-v1 中，草稿保存在 chan-kitchen-draft-v1 中。个人输入不会上传 GitHub 或其他服务器。不同设备、浏览器不自动同步。定期将 JSON 备份保存到 iCloud 或文件，清理浏览器数据前务必备份。站点源码公开，个人菜谱在本机。

## 开发与部署

单文件 HTML/CSS/JavaScript，无依赖。修改 recipes/index.html，提交 main，由仓库已启用的 GitHub Pages 从根目录自动发布。不要修改主站 index.html。预置番茄炒蛋仅为可编辑示例。

验证：浏览器新建、保存、刷新持久化、搜索、完整步骤显示、计时完成；390px 宽度布局检查。尚未进行真实 iPhone Safari 设备测试。
